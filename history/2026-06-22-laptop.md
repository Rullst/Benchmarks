# v1 results: 22 June 2026 (laptop, not comparable)

These numbers, the suite's first generation (v1), were measured by hand on
22 June 2026, before the suite was rebuilt on GitHub Actions (v2, 15 November
2026). They are kept only as a record. Do not compare them with the current
results:

- Hardware and setup differ: an AMD Ryzen 7 5700U laptop with 8 GB of RAM,
  Windows 11 and Docker on WSL2, with the server, the load generator and the
  database sharing all CPUs. Current results come from GitHub-hosted runners
  with pinned CPU sets.
- The runs are not reproducible: there is no recorded configuration, versions
  or raw output.
- Rullst was v12-era code (an Axum router wrapped by Rullst), not a current
  release.
- Several entries are evidently broken (for example FastAPI `/db-single` at
  2.49 requests/s, a 0.99 s average latency for Rails, 0 B of RAM for
  Laravel), and there was no conformance check, so some implementations did
  not return the expected responses.
- The "efficiency" score and pass/fail rule used at the time are not used
  any more.
